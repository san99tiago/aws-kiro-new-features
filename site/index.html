The four surfaces

Kiro CLI

Kiro in your terminal. Chat with the agent, run tools, and automate work in scripts and CI/CD with headless mode and an API key.

Kiro IDE

The agentic IDE. Turn ideas into specs (requirements, design, tasks), then let the agent build them, with hooks and steering to keep it on track.

How this repo works

  1. Specs are written in Kiro Web.
  2. Kiro Web opens pull requests and evolves the repo over time.
  3. On merge to main, GitHub Pages publishes this site.
  4. Each Thursday, headless Kiro researches and opens a PR with new findings.
